Bottle — Privacy Policy

Effective date November 21, 2026

About this policy

Bottle is a Discord bot that answers questions, holds short conversations, provides server utilities and offers optional moderation features. This policy covers data Bottle processes when you interact with the bot and data handled when you visit its legal pages.

Information Bottle receives and uses

  • Messages and commands. Bottle receives slash-command inputs and Discord message data made available by its permissions and settings. To answer, it uses the prompt, recent chat with you in that channel or thread, and text from a supported attachment when included. Direct messages and automatic replies are available only where enabled.
  • Discord identifiers. Bottle uses your user ID and message or interaction ID to respond, prevent duplicates, apply cooldowns, and count AI replies. It uses server and channel or thread IDs to route messages, keep conversation context separate, and apply server settings.
  • Staff and moderation data. /staff uses server membership and role information to produce a roster. Optional AutoMod is off by default. If server staff set it up, Bottle stores rule settings, rule and server IDs, any selected alert channel ID, and an audit history with action details, staff user IDs and timestamps. Enabled rules run in Discord. Bottle’s optional alert reports a block, the rule and the channel without quoting the blocked message.
  • Usage and diagnostics. Bottle uses timestamps, request and delivery states, warning records, provider names, token counts, response times and failure information to manage quotas, prevent spam, and diagnose problems. The limits in the inspected version are 30 successful replies per user and 150 shared across all servers per rolling 12 hours. Restricted operators can view provider usage summaries through /apistats.

AI processing by Groq

Bottle sends inference requests to Groq to generate responses. An inference request can include your prompt, accepted attachment text, recent conversation in the same scope, and Bottle’s instructions. User, server, and channel IDs used to operate Bottle are handled separately. Identifying details you type or attach can still be part of the content sent.

For AI safety review, Bottle can send Groq the current prompt, any accepted attachment text, and the proposed reply. The review request omits earlier conversation turns. Groq is the only external AI provider enabled in the configuration reviewed for this policy.

Groq documents retention of usage metadata and describes when it may temporarily retain inputs or outputs for reliability or abuse investigations. Email the operator for questions about the retention settings that apply to Bottle.

Storage and retention

Conversation context
Bottle keeps chat context in temporary memory, scoped by user and by server and channel or thread, or by direct message if enabled. Context expires 30 minutes after the latest delivered turn in the reviewed configuration. Older turns may be dropped earlier to stay within the context budget. A restart clears this chat memory. Conversation transcripts are kept out of Bottle’s SQLite database.
Request and provider records
Bottle stores request identifiers, user IDs, delivery status and timing in a SQLite database on the bot’s host. Successful reply records expire after 12 hours. Failed or abandoned requests can be kept for up to 24 hours for deduplication, and uncertain delivery can be held for 12 hours and one minute. Maintenance removes expired entries. Provider attempt records expire after one day.
Warnings, server settings and staff records
Quota warnings are cleared as quota becomes available. A provider-capacity warning can remain linked to a user ID until the user receives a successful reply. Channel settings and AutoMod configurations persist until changed or removed. The code has no fixed automatic expiry for AutoMod audit entries or stored staff roster snapshots. Staff snapshots are updated as rosters change and cleared when Bottle leaves the server.
Operational logs
Bottle’s application logs record operational events, error categories and timings without recording prompt or reply text in its logging calls. Email the operator for questions about any host logs or backups.

Sharing and visibility

Discord delivers commands, messages, replies, and optional moderation alerts. People with access to a server channel can see posts made there. Staff rosters and moderation alerts are shown in the relevant server according to its settings and Discord permissions.

Conversation context stays within its own user and chat scope. Bottle uses Discord user IDs across servers to apply per-user quotas and warning controls. The shared quota counts AI replies across servers. Groq receives the AI request data described above. The operator may disclose information where required by law.

Data security

Bottle connects to Discord and Groq over encrypted connections. It keeps AI conversation context in temporary memory, limits what goes into inference requests, and restricts access to moderator commands and provider usage summaries. Keep passwords, access tokens and sensitive personal information out of prompts and attachments.

Your choices, access and deletion

Run /forget in the channel or thread where you chatted with Bottle to clear your local AI conversation context there. Run it again in each separate chat you want to clear. Discord messages, copies already sent to Groq, and quota, staff, and moderation records follow their own retention rules. Use Discord’s controls to manage messages on Discord.

For access, correction, or deletion requests, use the privacy contact below. Include your Discord user ID and enough detail to identify the relevant records. The operator verifies that you control the account before disclosing or changing its data. Rights and obligations depend on applicable law.

Discord and age requirements

Bottle operates inside Discord. Discord manages your account, messages hosted on its platform and native AutoMod. To use Bottle, you must be at least 13 and meet Discord’s minimum age for your country. A parent or guardian can use the privacy contact below to raise a concern about a child’s data.

Contact & Data Requests

Email bottle.privacy@gmail.com to request access to or deletion of your personal data, raise a privacy concern, or ask about stored Discord information, third-party AI processing, or data retention.

For a data request, include your Discord user ID and a brief description of what you want to access or delete. The operator may ask you to confirm the request from your Discord account before acting on it. Keep passwords, tokens, and recovery codes out of your message.
